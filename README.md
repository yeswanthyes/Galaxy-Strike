## 🚀 About The Game
**Galaxy Strike** is an action-packed, fast-paced space shooter project. Navigate your way through the cosmos, face off against enemies, and explore dynamic environments! Built with the powerful Unity Engine, this project focuses on smooth gameplay, engaging mechanics, and high-quality assets.

## ✨ Features
- **Intense Action:** Fast-paced gameplay and responsive controls.
- **Stunning Environments:** Features beautiful terrain and space backdrops.
- **Customizable:** Built in a modular way within Unity, allowing for easy expansion.

## 🎮 Controls (Default)
* **W, A, S, D** or **Arrow Keys**: Movement
* **Spacebar** or **Left Click**: Fire / Action
* **Shift**: Boost 

*(Note: Controls can be customized within the Unity Input Settings)*

## 🛠️ Built With
* [Unity](https://unity.com/) - The game engine used
* **C#** - Core programming language

## ⚙️ Installation & Setup
To run the project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yeswanthyes/Galaxy-Strike.git
   ```
2. **Open Unity Hub.**
3. Click on **Open** -> **Add project from disk** and select the cloned `Galaxy-Strike` folder.
4. Open the project using a compatible Unity Editor version.
5. In the Project window, navigate to the `Assets/Scenes` folder and open the main scene.
6. Press the **Play** button at the top to test the game!

> ⚠️ **Note on Assets:** To keep this GitHub repository within size limits, large uncompressed binary assets (like raw `.tif` textures and `TerrainSampleAssets`) are excluded via `.gitignore`.
